# Avukat Aysel Kübra Sarı Web Sitesi

Bu proje, bir hukuk bürosu için geliştirilmiş modern ve responsive web sitesidir. React ve Supabase kullanılarak hazırlanmıştır. Web sitesinde ana sayfa, çalışma alanları, makale sayfaları, admin paneli ve iletişim alanları bulunmaktadır.

## Canlı Demo

https://avayselsaricaliskan.vercel.app

## Kullanılan Teknolojiler

- React
- Vite
- JavaScript
- React Router
- Supabase
- CSS
- Vercel

## Özellikler

- Responsive tasarım
- Mobil uyumlu arayüz
- Çalışma alanları sayfası
- Makale listeleme
- Makale detay sayfası
- Admin paneli
- Supabase ile içerik yönetimi
- WhatsApp iletişim butonu
- Vercel ile canlı yayınlama

## Proje Amacı

Bu proje, hukuk bürosunun dijital ortamda profesyonel şekilde temsil edilmesi ve kullanıcıların hizmet alanlarına, makalelere ve iletişim bilgilerine kolayca ulaşabilmesi amacıyla geliştirilmiştir.
